## A. 口径类（错一次就要返工）

| 症状 | 原因 | 解法 |
|---|---|---|
| 环比 +39.9% / +44.2% 这种离谱值 | 做成了「本期内部 W1 vs W2」 | 对比的是**本期两周 vs 上期两周**。见 [02-数据口径](02-数据口径.md) |
| 下载环比 +2211% | 一期是 14 天逐日、一期是 2 列周汇总，被当成同粒度 | 先算「本期总天数 ÷ 上期总天数」比值中位数，显著偏离 1 就停下问人 |
| 端游总量与上期报告对不上 | 词库变了 | 用**同一套词库**重算两期，不能用旧报告数字直接比 |
| 环比显示 `+nan%` | W1=0 的新上架游戏 | 用 `pd.isna(v)` 判断，不要用 `v is None`（pandas 会把 None 变 NaN） |
| 某游戏搜索量异常巨大 | 词库里有双字泛词（`超人`、`恐怖`） | 泛词放 `exclude`；或拆出专有词单算并在口径里注明 |
| 某游戏无论如何都不命中 | 游戏名含 `exclude` 里的词（如 `甜瓜游乐场` vs `甜瓜`） | `exclude` 是全局的，要么解开冲突，要么接受漏记 |
| 端游榜出现明显的手游 | 神策不区分端手游 | 查包名 / 安装包体积 / 渠道站；见 [02](02-数据口径.md) 第五节 |

## D. 网络 / 采集类

| 症状 | 原因 | 解法 |
|---|---|---|
| 封面大量回落 `generated` | 到 Steam 的连接**瞬时失败（HTTP 000）**，不是 404 | `fetch_url` 已内置 5 次退避重试，**重跑一次**通常就转 `real-og` |
| 新游封面 404 | 老 CDN 没有新游的 `header.jpg` | 走商店页 `og:image`（三级兜底已在 04b 实现） |
| `git push` 报 `CONNECT tunnel failed, 502` | 本机到 GitHub 网络抖动 | `for i in 1 2 3` 重试，通常第 2~3 次就过 |
| 判断 push 成功用了 `git push \| tail -3` | **管道退出码取的是 `tail` 的，恒为 0** | 必须看 `git push` 自身退出码，再用 `git ls-remote` 比远端 sha |
| 线上「200 就以为更新了」 | CDN / 多域名缓存 | **下载下来比 md5**，字节数相同也要比 |
| `git commit` 后中文名变八进制转义 | `core.quotepath` 默认 true | `git config core.quotepath false` |
| xlsx 被 CRLF 转换破坏 | Windows 上 `core.autocrlf` 默认 true | 仓库级 `git config core.autocrlf false` |

## G. 发布类（可选链路）

| 症状 | 原因 | 解法 |
|---|---|---|
| 部署后还是旧看板 | 发布目录是**独立副本**，不会自动同步 | 发布前先把本期看板复制到发布目录 |
| 部署报「预留域名未绑定…本次发布已停止」 | 域名从未绑定成功 | 日志里 `status="AVAILABLE"` 已返回 ⇒ **内容其实已上线**，用 `curl` 比 md5 判断 |
| GitHub Pages 中文文件名 404 | 缺 `.nojekyll` 或路径未编码 | 写 `.nojekyll` + `urllib.parse.quote` 分段编码 |
| 目录短链首访 404 | 新目录刚建立时必然 404 过一次，浏览器缓存了 | Ctrl+F5 / 无痕窗口 |

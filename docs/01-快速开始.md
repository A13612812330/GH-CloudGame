## 步骤 1 · 配置

两种方式二选一。

### 方式 A：图形界面（推荐给人工）

```bash
python pipeline/setup.py
```

弹窗里依次选择：

1. **数据根目录** —— 各级期目录的**上一级**（不是某一期目录）
2. **产出目录** —— 看板与 Excel 放这里
3. **本期期目录 / 上期期目录** —— 下拉自动列出，选最近的与次近的

点「保存并校验」，终端会打印解析结果。全绿说明可用。

### 方式 B：命令行（推荐给 AI Agent）

```bash
python pipeline/setup.py \
  --data-dir "/path/to/端游周报数据" \
  --out-dir  "/path/to/产出" \
  --cur 9.28-10.11 --prev 9.14-9.27 \
  --run-date 2026-10-12
```

不给 `--cur/--prev` 时，自动取数据根目录下**最近修改的两个期目录**。

随时体检当前配置：

```bash
python pipeline/setup.py --check
```

### 配置文件长什么样

`setup.py` 会写 `config.json`（已被 `.gitignore` 忽略）：

```json
{
  "data_dir": "D:/端游周报数据",
  "out_dir":  "D:/周报产出",
  "tmp_dir":  "D:/周报产出/_tmp_run",
  "assets_dir": ".../GH-CloudGame/assets",
  "period": {
    "cur":  { "label": "9.28-10.11", "dir": "9.28-10.11",
              "search": "搜索量9.28-10.11.xlsx", "dl": "鲸云下载.xlsx" },
    "prev": { "label": "9.14-9.27",  "dir": "9.14-9.27",
              "search": "搜索9.14-9.27.xlsx", "dl": "鲸云下载.xlsx" }
  },
  "run_date": "2026-10-12"
}
```

`search` / `dl` 留空也能跑 —— 脚本会按关键词自动探测。

## 步骤 3 · 跑流水线

**推荐一条命令到底**（含环境自检与门禁）：

```bash
cd pipeline
python 09_run_all.py
```

需要单步观察时：

```bash
cd pipeline
python 01_prep_search_dl.py
python 02_extract_steam_meta.py
python 03_build_steam_chart.py
python 04_build_report.py
python 04b_make_covers.py
python 05_gen_board.py
```

### 每步的期望输出

| 步骤 | 正常输出 |
|---|---|
| 01 | 打印「本期/上期」总量、Top20 榜单、涨幅榜 |
| 02 | `种子元数据: N 条` → `合并后 appid 总数: ~100` |
| 03 | `Top100 中端游候选 ~57 款`，缺失 0~11 款 |
| 04 | 打印 s4 重点表各行 |
| 05a | `OK hot_draft.json  12 条（封面计划 N 张）`，并逐条列出槽位，标 `🔴` 的是待人工 |
| 04b | 逐张打印封面来源 `real-cdn` / `real-og` / `cache` / `generated` |
| 05 | `OK HTML: <路径>  XXX KB` + `热门来源: ...` |

> **04b 是联网步骤**，首次跑较慢（每张封面 1~5 秒）。
> 出现 `generated` 多半是网络瞬时失败，脚本内置 5 次退避重试，**重跑一次**通常就转成真实图。
> 命中 `cache` 表示上次抓过的原图被复用（`{tmp}/raw_img/{appid}.jpg`）——
> 所以**同一台机器重复跑，封面字节稳定**；换机器首跑可能拿到体积不同的同一张图。

## 换成自己的数据

1. 按 `samples/` 的目录结构放好两期数据：

```
你的数据根目录/
├── <上期>/  搜索*.xlsx  +  *下载*.xlsx
└── <本期>/  搜索*.xlsx  +  *下载*.xlsx
```

2. 重跑 `setup.py` 指向新目录
3. `python 09_run_all.py --draft-hot --from 04` 生成热点初稿，按 `hot_review.md` 补第 11 条版号与归因
4. **读完 [AGENT.md](../AGENT.md) 第 4 节** —— SteamDB 快照、判定文案必须重写（热点 12 条已有半自动初稿）

## 常见启动失败

| 报错 | 原因 | 解法 |
|---|---|---|
| `[配置缺失] 未指定本期目录` | 没跑 setup 或 config 不在预期位置 | `python setup.py --check` |
| `[输入缺失] 找不到搜索表` | 目录名/文件名不匹配 | 看 `--check` 打印的路径 |
| `ModuleNotFoundError: pandas` | 依赖没装 | `pip install -r requirements.txt` |
| `Cannot find module 'jsdom'` | 没装 node 依赖 | `npm i jsdom` |
| `ENOENT ... Temp\data.json` | 用了 `TMP` 变量名 | 改用 `GH_TMP` |
